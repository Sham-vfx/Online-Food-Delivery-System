# Online Food Delivery System

A menu-driven C++ application developed for the LDCW6113 group project.

## Features

- Food category selection
- Local Food, Fast Food, Western Food and Drinks
- Multiple-item ordering
- Shopping cart
- Quantity selection
- Delivery fee calculation
- RM2 voucher discount
- Cash, Credit/Debit Card and E-Wallet payment options
- Invalid input handling
- Final order summary
